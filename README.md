# Amazon Homepage Layout (03CIT4053 Technology for Web Development)

Student: YIU TING MAK

A rebuild of the Amazon homepage using only normal flow, float, clear and the box
model. No flexbox, no CSS grid, no positioning and no framework are used.

## Structure

    25530933YiuTingMak/
        index.html
        css/style.css
        img/            (logo, banner, card and product images)

## How to open

Open `index.html` in any browser. The images and the stylesheet are linked with
relative paths, so no server is needed.
